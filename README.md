## 🏗️ Technical Architecture & Routing Engine

```
                          [ CLAIM INGESTION (FNOL) ]
                                       |
                     +-----------------v-----------------+
                     |   GATE 00 - CAPTURE INTEGRITY     |
                     |   - Direct-from-camera ONLY       |
                     |   - EXIF / Timestamp / GPS Lock   |
                     |   - Diffusion / Re-capture Screen |
                     +-----------------+-----------------+
                                       | Pass (Hard fail -> RED with 0 downstream calls)
                     +-----------------v-----------------+
                     |        5 SPECIALISED ENGINES      |
                     |   01 OCR First    deterministic   |
                     |   02 CV Depth     specialised ML  |
                     |   03 Fraud Graph  specialised ML  |
                     |   04 Parts Bench  deterministic   |
                     |   05 Policy RAG   targeted GenAI  |
                     +-----------------+-----------------+
                                       |
                     +-----------------v-----------------+
                     |     TRUST SCORE FUSION (0-100)    |
                     +--+--------------+--------------+--+
             Score >= 82 |     55 <= Score < 82       | Score < 55
                         v              v             v
                  +------------+ +------------+ +------------+
                  | GREEN  65% | | AMBER  25% | |  RED   10% |
                  | 0 touches  | | 1 reviewer | | full SIU   |
                  |  1.5 days  | |  3.5 days  | |  7.0 days  |
                  +------------+ +------------+ +------------+
```

### The 5 Engines & Score Allocation

| Engine | Layer | Mechanism | Weight |
|---|---|---|---|
| **Gate 00** | Layer 0 | Hardware & metadata integrity (tamper detection, EXIF, GPS, liveness) | **30%** |
| **01. OCR First** | Layer 1 | Deterministic document parsing (RC, licence, chassis, VAHAN registry) | **20%** |
| **02. CV Depth** | Layer 2 | Computer vision panel segmentation, severity grading, parts catalogue | **15%** |
| **03. Fraud Graph** | Layer 2 | Graph network analysis (shared garages, phone numbers, payout entities) | **25%** |
| **04. Parts Bench** | Layer 1 | Deterministic regional pricing benchmark (determines ₹50k cap trigger) | **—** |
| **05. Policy RAG** | Layer 3 | Targeted GenAI clause retrieval, exclusions and coverage validation | **10%** |

#### Critical Overrides
- **Gate 00 Hard Fail**: Immediately routes **RED**; downstream engines do NOT run.
- **Fraud Ring Score ≥ 0.35**: Immediately routes **RED** for Special Investigation Unit (SIU).
- **IRDAI Statutory Cap (> ₹50,000)**: Any claim > ₹50,000 is legally capped to **AMBER** for surveyor review under IRDAI guidelines.

## 💻 Running Locally

ClaimPulse requires **no build step, no bundler, and no external npm packages**. It is pure vanilla web technology (HTML5, CSS3, ES6).

```bash
# Clone the repository
git clone https://github.com/PratyushMathur2000/claimpulse-simulation.git
cd claimpulse-simulation

# Start a local static HTTP server
python -m http.server 8000
```

Open `http://localhost:8000` in your web browser.
